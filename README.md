# MB-to-YPAO

Convert the Magic Beans calibration output format to YPAO format and push it to the AVR.

## Installation

### Prerequisites

- [Magic Beans](https://magicbeansaudio.com/) (for calibration files)
- [Yamaha AVR](https://www.yamaha.com/en/products/audio_visual/av_receivers/) (for AVR)
- [Docker](https://www.docker.com/) (for container deployment)


### Docker

Pull the pre-built image:

```bash
docker run \
  --name mb-to-ypao \
  -p 5002:5002 \
  ghcr.io/f4data/mb-to-ypao:latest
```

Or use Docker Compose — create a `compose.yml` file:

```yaml
services:
  mb-to-ypao:
    image: ghcr.io/f4data/mb-to-ypao:latest
    container_name: mb-to-ypao
    ports:
      - "5002:5002"
    restart: unless-stopped
```

Then start it with:

```bash
docker compose up -d
```

## Usage

1. Switch ON your Yamaha AVR
2. **[Optional]** Perform YPAO calibration
2. Open a web browser and navigate to `http://localhost:5002` or `http://<docker_server_ip>:5002`
3. Provide the IP Address of your Yamaha AVR. 
4. **[Optional]** Check there is connectivity with AVR.
5. **[Optional]** Prepare the AVR for Magic Beans Calibration:
   - Either select **Through** to remove any previous calibration values (e.g YPAO)
   - Or select the **Flat** to preserve the R.S.C values from YPAO calibration
6. Run Magic Beans and store the calibration file(s)
7. Select the calibration file generated by Magic Beans (.txt) to upload
8. Select Apply
9. Manually set speaker sizes and crossover frequencies on AVR
10. Run Post Calibration adjustments on Magic Beans

## Yamaha AVR Models Tested

- Models with PEQ (Parametric EQ) support:
  Yamaha RX-V685


## Development
### Prerequisites

- [uv](https://docs.astral.sh/uv/) (Astral's Python package manager)
- Docker (optional, for container deployment)

### Local development

```bash
# Clone the repository
git clone https://github.com/f4data/MB-to-YPAO.git
cd MB-to-YPAO

# Install all dependencies (including dev tools)
uv sync --dev

# Run the application
uv run python -m mb_to_ypao.app
```

The app will be available at `http://localhost:5002`.

Optionally, the container can be built and run locally:

```bash
# Build the image
docker build -t mb-to-ypao .

# Run the container
docker run \
  --name mb-to-ypao \
  -p 5002:5002 \
  mb-to-ypao
```


### Run tests

```bash
uv run pytest tests/ -v
```

### Lint and format

```bash
# Check for lint issues
uv run ruff check src/ tests/

# Auto-fix fixable issues
uv run ruff check --fix src/ tests/

# Check formatting
uv run ruff format --check src/ tests/

# Apply formatting
uv run ruff format src/ tests/
```

### Type checking

```bash
uv run mypy src/
```
